# Analysis wrappers post pipeline


We provide a list of analysis methods downstream of the pipeline, including wrapper functions or vignettes for easy use:

1. Cell-type comparisons and subclustering: [`comparative_module()` and `subset_module()`](Subclustering_and_ComparativeModule_Vignette.md)

2. aPEAR for network based enrichment analysis of DE pathways: [aPEAR scDAPP wrapper vignette](aPEAR_wrapper.md)

3. Tutorial for creating a web-compatible app using the scDAPP output files using ShinyCell: [ShinyCell vignette](ShinyCell_tutorial.md)
